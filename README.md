# hxyfront-62007 植物标本馆入库 · 干燥轮换工作台

源提示词编号：9

植物标本馆压制标本入库前端：录入采集号、物种名称、采集地点、海拔、生境描述、采集人、
压制状态、鉴定状态和馆藏位置；压好的标本凭现有采集号进入待干燥队列，在轮换工作台登记
架位、翻面时间和称重，并提供入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和
单份标本详情页。

## 轮换业务规则

- 每份标本用**现有采集号**进入待干燥队列，首次上架登记架位、翻面时间、首称。
- **相邻两次轮换不能停在同一架位**。
- 重量严格下降才算减重；**连续两次没有下降（含持平）→ 转待复压**，待复压标本
  **不能送去鉴定**。
- 目标架位已被其他在架标本占用，或本次称重**高于**上次时，本次操作不保存——
  原架位、轮换记录和标本状态维持原样。
- 待复压标本在工作台勾选“补做”，本次称重比上次少 ≥0.5g（明显减重）即干燥完成、
  回到待鉴定，随后可送去鉴定或登记上柜。

## 数据持久化

所有页面（采集地点卡、待干燥队列、柜位台账、标本总览、详情页）读取同一份
`localStorage` 数据（键 `hxyfront-62007-herbarium-archive-v1`），每次变更即时写入，
重开浏览器仍可查询；支持多标签页 `storage` 事件同步，并提供“恢复演示数据”。

## 代码分层（三个独立业务方向）

| 目录/文件 | 职责 |
| --- | --- |
| `src/domain/archive.ts` | **资料存档**：localStorage 读写、种子数据、入队/上架/鉴定/上柜等数据操作 |
| `src/domain/rotationRules.ts` | **轮换判断**：纯函数业务规则（架位冲突、同架位、称重比较、待复压/补做判定），不依赖 React 与存储 |
| `src/domain/types.ts` | 领域类型与常量（架位、阶段、明显减重阈值） |
| `src/hooks/useArchive.ts` | 全应用唯一浏览器数据入口 |
| `src/components/*` | **页面交互**：轮换工作台、入库表单、筛选、地点卡、柜位记录、详情弹窗 |

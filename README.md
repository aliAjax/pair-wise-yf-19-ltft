# hxyfront-62007 植物标本馆入库 · 干燥轮换工作台

源提示词编号：9

植物标本馆压制标本入库前端：工作人员录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置；页面包含入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

本版本补充了标本压好后的**干燥架轮换工作台**。

## 轮换业务规则

1. 标本压好后凭**现有采集号**进入「待干燥队列」。
2. 每次上/换架登记**架位、翻面时间、称重**；相邻两次不能停在同一架位。
3. 重量**连续两次没有下降**（持平也算）→ 自动转「待复压」，且不能送去鉴定/上柜。
4. **目标架位已被其他在架标本占用**，或**本次称重高于上次** → 本次操作不保存：原架位、轮换记录、标本状态全部维持原样，页面给出原因提示。
5. 待复压后补做一次**明显减重**（相对上次 ≥ 3% 或绝对减重 ≥ 0.5 g）→ 回到「待鉴定」，鉴定通过后登记柜位上柜。

## 代码结构（职责分离）

| 文件 | 职责 |
| --- | --- |
| `src/archive.ts` | **资料存档**：localStorage 读写、种子数据、队列/架位占用/柜位/地点查询 |
| `src/rotation.ts` | **轮换判断**：入队、轮换校验与状态流转、上柜的纯业务规则（不碰 DOM） |
| `src/workbench.tsx` | **页面交互**：工作台 React 组件，只收集输入、调用前两个文件并渲染 |
| `src/types.ts` | 共享类型定义 |

采集地点卡、待干燥队列、柜位记录和详情页读取同一份浏览器数据（localStorage 键
`herbarium.archive.v1`），关闭重开浏览器后仍可查询。判断失败的轮换不会写存档。
